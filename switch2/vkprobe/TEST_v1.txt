gr_vkprobe v1: how to test
==========================

Copy gr_vkprobe.nro to the SD card and start it from hbmenu. It does not crash on purpose:
it lists what the Switch 2's Vulkan driver (OunceVK) supports and waits.

1. Start gr_vkprobe. Wait for "== done. Press + to exit." (a few seconds).
   If it stops earlier, note the last line on the screen.
2. Press + to exit.
3. Copy sdmc:/gr_vkprobe.txt into switch2/logs/.
